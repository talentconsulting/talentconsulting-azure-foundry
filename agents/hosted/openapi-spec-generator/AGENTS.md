# OpenAPI Spec Generator

This project was built with the microsoft-foundry skill. Before working on or answering questions about Foundry agents, read the microsoft-foundry skill first.

- Keep runtime code under `src/openapi-spec-generator/`.
- Preserve the exact `apiFile` and `supportingFiles` input contract.
- Return the OpenAPI document itself as JSON, without Markdown or a wrapper.
- Keep source access restricted to credential-free GitHub blob URLs from one repository and ref.
- Run the unit tests before deployment.
