# OpenAPI Spec PR Creator

This project was built with the microsoft-foundry skill. Before working on or answering questions about Foundry agents, read the microsoft-foundry skill first.

- Keep runtime code under `src/openapi-spec-pr-creator/`.
- Never commit GitHub credentials; read `GITHUB_PR_TOKEN` from the environment.
- Treat the destination repository as runtime input.
- Create a branch and pull request, but never approve or merge it.
- Run the unit tests before deployment.
